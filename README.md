# Borshevik Glass

A GNOME Shell extension that gives the top panel, the overview, the app grid, the dash and app folders a frosted-glass look: the wallpaper shows through them, blurred and tinted dark or light to follow GNOME's colour scheme. The blur is static — the wallpaper is blurred once, not the screen at every frame — so the look costs next to nothing in GPU time and battery.

Made for [Borshevik Linux](https://borshevik.org), where it replaces Blur my Shell.

To work on it, see [AGENTS.md](AGENTS.md).
